# Paradise Nursery — Plant Shopping Application

## Project Overview
Paradise Nursery is an online plant shopping application where users can explore indoor plants, view their prices, and add plants to a shopping cart.

## Features
- Attractive landing page with a Get Started button.
- About Us section describing Paradise Nursery.
- Plant categories and product cards.
- Add plants to the shopping cart.
- Increase or decrease item quantities.
- Remove products from the cart.
- Automatic subtotal and total price calculations.
- Checkout confirmation.

## Technologies Used
- React.js
- JavaScript
- CSS
- Redux Toolkit
- React Redux

## Main Components
- `App.jsx` — Main application and navigation.
- `App.css` — Application styling.
- `AboutUs.jsx` — About the nursery.
- `ProductList.jsx` — Plant listings and Add to Cart functionality.
- `CartSlice.jsx` — Redux cart state management.
- `CartItem.jsx` — Cart quantities, deletion, totals, and checkout.
